# 2026-the-great-ctf-debrief

Writeups for every challenge from this event, written so a **beginner can follow along** and an **expert can skim**.

## How this works (the whole thing in 30 seconds)
- **Every challenge is one folder** with a `README.md` inside it.
- The top of each writeup has a small `--- ... ---` info block (category, difficulty, flag, tags). **That block is the source of truth** — the tables below are built from it automatically.
- Chained CTFs are grouped as series folders (e.g. `blackstar/`); standalone challenges by category (`web/`, `forensics/`, …).
- You mostly just open this page, click a challenge, and read.

## Add a new challenge (easy mode)
Pick whichever you prefer:
- **Easiest:** tell Claude *"write up &lt;challenge&gt; for &lt;event&gt;"* — it creates the folder and refreshes the tables.
- **Yourself:** from the `CTFs/` folder run
  ```
  python ctf.py new 2026-the-great-ctf-debrief/web/my-challenge
  ```
  fill in the new `README.md`, then run `python ctf.py` to rebuild all the tables. Done. Commit & push.

> You never edit the tables by hand. `python ctf.py` regenerates them from the writeups.
